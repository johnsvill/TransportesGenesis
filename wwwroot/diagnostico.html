📋 Instrucciones para Corregir Enlaces:
  1. Crear Usuario Padre de Prueba: Usa el botón de arriba para crear padre.test
  2. Probar Login como Padre: Ve a /Auth/Login con padre.test/123456
  3. Verificar Enlaces: Una vez logueado como padre, usa los botones de "Enlaces Directos de Prueba"
  4. Dashboard Principal: El dashboard de padres debería estar en /PagosPadresFamilia
  5. Si hay errores 404: Significa que las páginas necesitan autorización de rol "PadreDeFamilia"
⚠️ Importante: Debes estar logueado como un usuario con rol "PadreDeFamilia" para acceder a estas páginas.
